# Build vs reuse — GATE (run before any implementation)

Этот блок — жёсткий шлюз, а не совет. Он относится к ЛЮБОЙ задаче, где что-то создаётся, ставится, подключается или скриптуется: включая «маленький вспомогательный скрипт», пайплайн сцен, цепочку промптов, кусок UI. Нарушение этого правила — самая дорогая ошибка в истории этого профиля.

**Шаг 0 — сначала локальные скиллы.** Если в каталоге сессии есть `reuse-first` — загрузить его инструментом `skill` и выполнить его порядок поиска дословно. Если есть скилл под задачу (Office-файлы, DSH-плагины, диагностика, коммиты, ревью) — загрузить и его. Запрещено заново реализовывать шаги загружаемого скилла: никаких самодельных поисковых скриптов, самописных API-клиентов и «своего быстрого инструмента», если в скилле уже указаны точные endpoints.

**Шаг 1 — поиск в этом порядке, с таблицей в ответе:**
- Маркет плагинов DSH: `https://aaamechanic.github.io/dsh-plugin-market/index.json`, `https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json`
- npm: `https://registry.npmjs.org/-/v1/search?size=60&text=<query>` + `https://api.npmjs.org/downloads/point/last-month/<name>`
- GitHub: `https://api.github.com/search/repositories?q=<query>&sort=stars&order=desc`, затем прочитать свежие открытые issues
- Hugging Face: `https://huggingface.co/api/models?search=<query>`
- Проверить, что уже поставляет сам рантайм (`dsh-base`, установленные бандлы, `package.json` профиля), прежде чем считать, что пробел существует.

Сеть в этом окружении: `node -e "fetch(...).then(r=>r.text()).then(t=>console.log(t))"`. `web_fetch` может падать с «multiple usable web providers»; TLS в PowerShell не работает.

**Шаг 2 — судить по поддержке, а не по звёздам:** дата последней публикации, загрузки в месяц, открытые issues про текущую версию рантайма, `engines.dsh` против установленной версии DSH, лицензия.

**Шаг 3 — решение из четырёх:** использовать как есть (проверить одним реальным вызовом) → настроить/форкнуть → строить только доказанный пробел → строить с нуля, только если сопоставимого нет. Затем одной строкой сказать, что найдено, что выбрано и что отвергнуто, — до первой строки кода.

Триггерные слова, которые всегда открывают шлюз: «сделай», «поставь», «настрой», «установи», «напиши», «инструмент», «скилл», «плагин», «пайплайн», «MCP», «3D», «анимация», «рендер», «автоматизация».
