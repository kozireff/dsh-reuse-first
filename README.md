# Установка правила «не изобретать колесо» в DeepSeek Harness

Ставит на машину два глобальных элемента DSH:

1. **скилл** `reuse-first` → `%USERPROFILE%\.dsh\skills\reuse-first\SKILL.md`
2. **раздел-шлюз** в `%USERPROFILE%\.dsh\AGENTS.md` (глобальные инструкции, подмешиваются в каждую сессию)

## Быстрая установка (Windows)

```powershell
git clone https://github.com/<твой-аккаунт>/dsh-reuse-first.git
cd dsh-reuse-first
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт:

- копирует `skills\reuse-first\` в `%USERPROFILE%\.dsh\skills\` (существующий скилл заменяется — сначала делает `.bak`);
- создаёт `%USERPROFILE%\.dsh\AGENTS.md`, если его нет;
- добавляет раздел-шлюз, если в файле ещё нет маркера `## Build vs reuse — GATE`;
- печатает, что сделано, и требует перезапустить сессию DSH (инструкции читаются при старте сессии).

## Ручная установка

```powershell
# 1) скилл
mkdir "$env:USERPROFILE\.dsh\skills\reuse-first" -Force
copy skills\reuse-first\SKILL.md "$env:USERPROFILE\.dsh\skills\reuse-first\SKILL.md"

# 2) правило: дописать GATE.md в конец глобальных инструкций
Get-Content GATE.md | Add-Content "$env:USERPROFILE\.dsh\AGENTS.md"
```

## Проверка, что сработало

1. Перезапустить DSH (или открыть новую сессию).
2. Убедиться, что в каталоге скиллов появился `reuse-first` (в чате: попросить «покажи доступные скиллы» либо посмотреть файл).
3. Дать задачу вида «сделай мне инструмент для X» — агент обязан сначала загрузить `reuse-first`, показать таблицу кандидатов с датами/загрузками/issues и только затем писать код.

## Состав репозитория

| Файл | Назначение |
|---|---|
| `GATE.md` | текст раздела-шлюза, который дописывается в `AGENTS.md` |
| `AGENTS.full.md` | полный `AGENTS.md` с этого профиля (для сверки/переноса целиком) |
| `skills/reuse-first/SKILL.md` | сам скилл: порядок поиска по маркету DSH → npm → GitHub → Hugging Face |
| `install.ps1` | установка на Windows |

## Почему это нужно

Без шлюза агент начинает изобретать: пишет свои поисковые скрипты, самописные клиенты к API и «быстрые инструменты» вместо того, чтобы выполнить порядок поиска из скилла. Правило фиксирует: сначала загрузить скилл и искать готовое, показать таблицу поддержки, и лишь потом строить — и только доказанный пробел.
